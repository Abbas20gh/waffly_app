# Waffly — نرم‌افزار مدیریت و حسابداری تولید نان سنتی

> نان بستنی فانتزی ایتالیایی • آفلاین‌محور • تقویم شمسی • ۳ کاربر هم‌زمان • APK یونیورسال اندروید

## ۲) دیتابیس (۱۴ جدول سینک‌پذیر)

| جدول | توضیح |
|---|---|
| `products` | انواع نان + کد ۲ رقمی برای کد جعبه + طعم (قابل افزودن در آینده) |
| `customers` / `suppliers` | خریداران و تامین‌کنندگان با پروفایل کامل |
| `materials` | مواد اولیه با **واحد اختصاصی** (کیلوگرم/کیسه/گونی/...) و حد بحرانی |
| `productions` | تولید روزانه: کل تولید، جعبه‌ها، نان در هر جعبه، **پرتی**، **باقیمانده روز قبل + تاریخ اصلی** |
| `boxes` | هر جعبه با **کد یکتای ۱۰ رقمی** — آماده اسکن بارکد/QR در آینده |
| `materialUsages` | مصرف دستی روزانه هر ماده |
| `sales` | فروش: اقلام JSON، برگشتی، **تسویه کامل/جزئی**، روش پرداخت، **چک (شماره/بانک/سررسید)**، تاریخ واقعی واریز |
| `purchases` | خرید مواد با تسویه جزئی |
| `machineProjects` + `machineCosts` | الف) پروژه‌های دستگاه نانوایی (پیشرفت + هزینه) ب) دستگاه‌سازی کلی — هر دو با «مواد مصرفی» و «قطعات سرمایه‌ای» (بدون استهلاک) |
| `expenseCategories` + `expenses` | **معین‌ها**: دسته‌های هزینه دلخواه + کلید «در فرمول سود» |
| `settings` | روز شروع دوره حسابداری، آستانه بدحسابی، آستانه هشدار چک |
| `syncLog` | لاگ افزایشی سینک (seq خودافزا) |

هر رکورد: `id` (تولید در کلاینت) + `createdAt/updatedAt` (میلی‌ثانیه) + `deleted` (تومب‌استون) — همه تاریخ‌ها **رشته شمسی** `YYYY/MM/DD`.

## ۳) فرمت کد یکتای جعبه (۱۰ رقم)

```
TT  DD  MM  NN  SS
│   │   │   │   └── شماره سری جعبه در همان روز/نوع/ظرفیت
│   │   │   └────── تعداد نان داخل جعبه (۰۱–۹۹)
│   │   └────────── ماه تولید شمسی
│   └────────────── روز تولید شمسی
└────────────────── کد نوع نان (۰۱=بزرگ، ۰۲=متوسط، ...)
```
مثال: `0115072003` = جعبه سوم از نان بزرگ (کد ۰۱)، تولید ۱۵ مرداد، هر جعبه ۲۰ عدد.
`formatBoxCode` آن را به شکل `01 15 07 20 03` نمایش می‌دهد؛ برای QR آینده: `WF + کد` (تابع `qrPayload`).

## ۴) فلوی آفلاین و سینک

1. **هر خواندن/نوشتن از IndexedDB** → سرعت بالا، بدون نیاز به اینترنت.
2. هر نوشتن → رکورد در Dexie + یک ورودی در صف `outbox`.
3. موتور سینک (debounce ۱.۵ ثانیه + دوره ۲۰ ثانیه + رویداد `online` + socket):
   - **push**: `POST /api/sync/push` → سرور با **LWW** (`updatedAt`) اعمال می‌کند
   - **pull**: `GET /api/sync/pull?since=cursor` → تغییرات دیگران با LWW سمت کلاینت
4. **real-time**: بعد از هر push موفق، سرور از طریق socket.io به همه کلاینت‌ها `data-changed` می‌فرستد → pull فوری (تأخیر معمولاً < ۱ ثانیه).
5. **تعارض**: آخرین ویرایش برنده است (بر اساس ساعت دستگاه + timestamp میلی‌ثانیه). حذف‌ها هم تومب‌استون می‌شوند و سینک می‌شوند.
6. دستگاه جدید: `GET /api/sync/full` (اسنپ‌شات) + seed خودکار داده‌های پایه.
7. ابزار «تعمیر سینک» در تنظیمات: همه داده محلی دوباره در صف قرار می‌گیرد (رفع هرگونه ناهماهنگی).
8. **پشتیبان‌گیری**: خودکار روزانه روی سرور (فایل `.db`، ۱۴ نسخه) + خروجی/ورودی JSON دستی.

## ۵) صفحات UI

| صفحه | محتوا |
|---|---|
| **داشبورد** | ۵ کارت ماژول، آمار دوره، هشدارهای فعال (موجودی/بدحساب/چک)، نمودار فروش‌وسود ۶ دوره، روند سودآوری، پرفروش‌ترین خریداران |
| **تولید** | ثبت روزانه (۳ فیلد اصلی + پرتی + باقیمانده با تاریخ اصلی)، تب جعبه‌ها با کد یکتا، تب مصرف مواد با پیش‌نمایش |
| **فروش** | فروش چندقلمی، تسویه کامل/جزئی، چک با سررسید، برگشتی، تب خریداران، تب بدحساب‌ها با روزهای تأخیر |
| **خرید مواد** | خرید با واحد اختصاصی، تامین‌کنندگان + سابقه، موجودی زنده (خرید−مصرف) و تنظیم حد بحرانی |
| **دستگاه‌سازی** | دو تب جدا: الف) پروژه‌های نانوایی با پیشرفت و هزینه‌های ریز ب) دستگاه‌سازی کلی |
| **حسابداری** | ناوبری دوره‌ای شمسی، آمار فروش/وصول/معوق، **سود سه‌حالته**، جدول معین‌ها با وضعیت لحاظ در سود، گزارش خریداران + رتبه + سرعت تسویه، چک‌ها، واریزی‌ها؛ خروجی Excel (۵ شیت RTL) و PDF |
| **تنظیمات** | نام کسب‌وکار، روز شروع دوره، آستانه‌ها، سینک فوری/تعمیر، پشتیبان‌ها |

طراحی: راست‌به‌چپ کامل، فونت وزیرمتن، اعداد فارسی، دکمه‌های بزرگ لمسی، ناوبری پایین در موبایل + سایدبار در تبلت.

## ۶) نصب و راه‌اندازی APK

1. فایل `waffly-v1.0-universal.apk` را روی اندروید (۷ به بالا) نصب کنید (اجازه «منابع ناشناس»).
2. در اولین اجرا، **آدرس سرور** را وارد کنید (همان آدرس پیش‌نمایش تحویل‌شده) — یک‌بار برای همیشه ذخیره می‌شود.
3. اپ یک بار با اینترنت کامل بارگذاری می‌شود؛ پس از آن حتی بدون اینترنت کار می‌کند و داده‌ها محلی ذخیره/سینک می‌شوند.
4. خروجی‌های Excel/PDF در پوشه **Downloads** ذخیره می‌شوند.
5. برای نصب PWA بدون APK: کروم ← «افزودن به صفحه اصلی».

## ۷) فازبندی توسعه

**نسخه ۱ (فعلی — تحویل‌شده):** همه ۵ ماژول، سینک آفلاین LWW + real-time، داشبورد گرافیکی، هشدارها، پشتیبان خودکار، خروجی PDF/Excel، PWA + APK، تقویم شمسی کامل، ۳ کاربر هم‌سطح.

**نسخه ۱.۱:** اسکن بارکد/QR جعبه‌ها (زمینه آماده: کد ۱۰ رقمی + `qrPayload`)، مرتب‌سازی چک‌های دریافتی، نمودار مقایسه محصول، قالب فاکتور چاپی.

**نسخه ۲:** احراز هویت چندکاربره با پین/نقش، گردش انبار پیشرفته (رسید/حواله)، فرمول‌بندی تولید (BOM) و کسر خودکار مواد، اپ iOS.

**نسخه ۳:** هوش تجاری پیشرفته (پیش‌بینی فروش)، اتصال درگاه پرداخت، پیامک یادآوری به مشتریان بدحساب.
