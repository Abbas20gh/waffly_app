بخش 1 — خلاصه کلی: دو پروژه چی هستن
================================================================

در این مجموعه دو پروژه جدا ولی مرتبط ساخته شده است:

(1) فروشگاه آنلاین «نان بستنی آرتا»  →  https://artanon.ir
    - سایت عمومی برای مشتریان: دیدن محصولات، خرید عمده جعبه‌ای،
      ثبت سفارش مهمان (بدون ثبت‌نام)، پیگیری سفارش با سریال+موبایل
    - پنل ادمین خصوصی برای شما: دیدن/مدیریت سفارشات، محصولات،
      استان‌ها و هزینه ارسال، شماره کارت
    - تکنولوژی: Next.js 16 + Tailwind 4 + پرisma + دیتابیس Turso (ابری)
    - میزبانی: Netlify (رایگان) + Cloudflare (DNS، SSL و سرعت، رایگان)
    - دامنه: artanon.ir ثبت‌شده در NIC.ir
    - ریپو گیت‌هاب: Abbas20gh/waffly_app — برنچ «arta-site»

(2) اپ مدیریت تولید و فروش «وافلی» (Waffly)
    - اپ خصوصی داخلی کارخانه/گروه: مدیریت تولید، جعبه‌ها و کدهای چاپی،
      مواد اولیه و خرید، فروش، انبار، دستگاه‌ها، حسابداری،
      حساب‌های بانکی/صندوق، صدور فاکتور و ارسال به تلگرام
    - سه شکل: وب (https://waffly.pages.dev) + اپ اندروید (APK) + آفلاین کامل
    - تکنولوژی: Next.js 16 + Prisma + Dexie (آفلاین) + سینک ابری با Turso
      + Cloudflare Pages (بک‌اند) + Capacitor (اندروید)
    - دیتابیس ابری: libsql://waffly-db-abbas20gh.aws-eu-west-1.turso.io
    - ریپو گیت‌هاب: Abbas20gh/waffly_app — برنچ «main»

نکته مهم: هر دو پروژه در «یک» ریپو گیت‌هاب زندگی می‌کنند:
    - برنچ main      = اپ وافلی
    - برنچ arta-site = فروشگاه آنلاین آرتا
دیتابیس‌های Turso هم جدا هستند (waffly-db برای اپ، arta برای فروشگاه).

2-9) ماجرای دامنه و SSL — خلاصه عیب‌یابی (برای مرجع آینده)
---------------------------------------------------------------

مشکل: سایت با artanon.ir باز نمی‌شد؛ مرورگر خطای امنیتی می‌داد.

عیب‌یابی قدم‌به‌قدم:
  1) whois.nic.ir چک شد → هر ۴ نیم‌سرور Netlify درست ثبت بود
  2) dig +trace → زنجیره delegation سالم
  3) رکوردها درست بودند؛ سایت با HTTP ساده هم جواب می‌داد
  4) ریشه مشکل: گواهی SSL برای artanon.ir صادر نشده بود —
     سرور گواهی پیش‌فرض *.netlify.app می‌فرستاد → خطای مرورگر
  5) در Netlify چند بار Verify/Provision/re-add امتحان شد؛
     DNS تأیید می‌شد ولی صدور گواهی همیشه خطای عمومی می‌داد
     (سیستم صدور Netlify برای این اکانت گیر کرده بود)

راه‌حل نهایی — مهاجرت DNS و SSL به Cloudflare (رایگان):
  1) اکانت رایگان Cloudflare + Add a domain: artanon.ir (پلن Free)
  2) حذف رکوردهای import شده؛ ساخت ۲ رکورد:
       A     @   → 75.2.60.5            (پروکسی نارنجی ON)
       CNAME www → artanon.netlify.app  (پروکسی نارنجی ON)
  3) تعویض نیم‌سرورها در NIC.ir:
       حذف: dns1 تا dns4.p04.nsone.net
       افزودن: colin.ns.cloudflare.com و luciane.ns.cloudflare.com
  4) SSL/TLS در Cloudflare: حالت Full
  5) نتیجه: رجیستری ایران فقط ~۲ دقیقه بعد NS جدید را اعمال کرد؛
     گواهی Universal SSL کلادفلر در ~۲ دقیقه صادر شد
     (CN=artanon.ir + *.artanon.ir)
  6) نکته جالب: در همان لحظات Netlify هم گواهی خودش را صادر کرد —
     الان دو لایه TLS معتبر داریم

وضعیت نهایی: همه‌چیز سبز — سایت از ایران و خارج، با IP ایران و
بدون فیلترشکن، با قفل سبز باز می‌شود.

درس مهم (اگر دوباره مشکل SSL داشتید): سیستم صدور گواهی Netlify را
دست نزنید؛ SSL از طریق Cloudflare مدیریت می‌شود و خودکار است.

بخش 5 — مشکلات بزرگ حل‌شده (درس‌های پروژه)
================================================================

1) سینک دوطرفه وب↔گوشی کار نمی‌کرد → ریشه: CORS در WebView اندروید.
   فیکس نهایی: CapacitorHttp (استک HTTP نیتیو) — نه تغییر سرور.
   درس: خطای «ظاهراً شبکه» در اپ اندروید را اول با CORS چک کنید.

2) pull بعد از ~۵۰ رکورد خطا 500 می‌داد → سقف ۵۰ subrequest کارگران
   Cloudflare. فیکس: pull گروهی (IN) و push دسته‌ای (batch per table).

3) لیست کشویی داخل دیالوگ‌ها لمس نمی‌شد (گوشی واقعی) → تعارض Radix
   Dialog با منوی Portal. فیکس سراسری در ui/dialog.tsx + InlinePicker.
   درس: تست این باگ‌ها فقط با ورودی واقعی ممکن است (eval click باگ را
   پنهان می‌کند).

4) PDF فاکتور در مرورگر هنگ می‌کرد (react-pdf) → مهاجرت به
   html2canvas-pro + jsPDF. نکته فنی: رندر موقت بیرون از صفحه.

5) تاریخ‌های فارسی (ارقام فارسی) دیتابیس را خراب می‌کردند →
   نرمال‌سازی در کلاینت + whitelist سمت سرور.

6) سایت آرتا با دامنه باز نمی‌شد → گواهی SSL صادر نشده. سیستم صدور
   Netlify برای این اکانت گیر کرده بود؛ حل نهایی: مهاجرت DNS/SSL به
   Cloudflare (۲ دقیقه!). درس: SSL را از CDN مدیریت کنید، نه از هاست.

7) اکانت‌های Vercel/Render از ایران مشکل داشتند (فلگ ضدتقلب / کارت
   Stripe) → Netlify + Cloudflare همه‌چیز را بدون کارت حل کرد.

بخش 7 — فرم «تغییرات موردنظر» (اینجا را پر کنید)
================================================================

راهنما: هر تغییری که می‌خواهید را در یک خط بنویسید؛ ستون «بخش» را از
حروف راهنما انتخاب کنید. این جدول را همین‌طور که هست برای من بفرستید
تا یکی‌یکی اجرا کنم.

فرمت هر خط:
  تغییر موردنظر | بخش مربوطه | توضیح/جزئیات (اختیاری)

کد بخش‌ها:
  SHOP-PAGES  = صفحات/متن‌های سایت        SHOP-PROD  = محصولات و قیمت‌ها
  SHOP-SEND   = ارسال/استان‌ها            SHOP-ADMIN = پنل ادمین
  SHOP-PAY    = پرداخت/درگاه             SHOP-DESIGN= ظاهر سایت
  W-GEN       = اپ وافلی - عمومی          W-SALE     = فروش/فاکتور
  W-PROD      = تولید/جعبه‌ها             W-BUY      = خرید/انبار
  W-ACC       = حسابداری/حساب‌ها          W-TEL      = تلگرام
  INFRA       = دامنه/هاست/DNS/SSL        OTHER      = سایر

نمونه‌های پرشده (نمونه است — تغییرش دهید یا پاک کنید):
  تغییر قیمت نان فانتزی کوچک به 4000 تومان        | SHOP-PROD | از پنل ادمین قابل انجام است
  افزودن اسانس جدید «وانیل»                        | SHOP-PROD | در فروشگاه و اپ هر دو
  هزینه ارسال تهران 200000 بشود                    | SHOP-SEND | از پنل ادمین
  بنر تخفیف پاییزه در صفحه اصلی                    | SHOP-PAGES | متن + تاریخ
  درگاه زرین‌پال وصل شود                            | SHOP-PAY | شماره ملی/کد اقتصادی لازم است
  سربرگ فاکتور آدرس کارخانه داشته باشد             | W-SALE | آدرس را بدهید
  رنگ دکمه‌های سایت شکلاتی‌تر شود                   | SHOP-DESIGN | هگز رنگ مطلوب
  گزارش ماهانه سود پیامک شود                       | W-ACC | نیاز به سرویس پیامک

بخش 8 — پیوست: گیت‌هاب، بیلد و نگهداری
================================================================

ریپو یکتا، دو برنچ:
  https://github.com/Abbas20gh/waffly_app
    main      → وافلی (دیپلوی: Cloudflare Pages خودکار از main)
    arta-site → فروشگاه (دیپلوی: Netlify خودکار از arta-site)
  قانون طلایی: تغییر فروشگاه فقط روی arta-site؛ تغییر اپ فقط روی main.

بیلد و دیپلوی فروشگاه (خودکار است):
  git push → Netlify build (~۱ دقیقه) → انتشار خودکار
  محتوای مهم: netlify.toml | next.config.ts (خروجی شرطی NETLIFY)
  اگر روزی Netlify عوض شد: رکوردهای Cloudflare را به هاست جدید بچرخانید.

بیلد و دیپلوی وافلی وب:
  node scripts/build-pages.mjs        (بیلد استاتیک + تزریق نسخه در SW)
  npx wrangler pages deploy out --project-name=waffly --branch main
  (نیازمند CLOUDFLARE_API_TOKEN + CLOUDFLARE_ACCOUNT_ID در env لحظه بیلد)

بیلد APK وافلی:
  1) node scripts/build-pages.mjs     (با NEXT_PUBLIC_API_BASE=https://waffly.pages.dev)
  2) npx cap sync android
  3) cd android && JAVA_HOME=.jdk21 ./gradlew assembleRelease
  خروجی: android/app/build/outputs/apk/release/app-release.apk
  قاعده: هر نسخه → versionCode +1 و versionName جدید در android/app/build.gradle

اسکریپت‌های مهم موجود در ریپو (scripts/):
  build-pages.mjs          بیلد استاتیک Cloudflare
  seed-arta.ts             seed فروشگاه (محصولات/استان‌ها/تنظیمات)
  turso-setup-arta.ts      ساخت جدول‌های فروشگاه روی Turso
  test-netlify-arta.sh     تست دود کامل فروشگاه
  verify-yazd.sh           تست دود (یزد/کارت)
  backup-turso.mjs         بکاپ JSON از Turso (وافلی)
  compare-counts.mjs       مقایسه تعداد رکوردهای محلی/سرور
  cleanup-server-dupes.mjs پاک‌سازی رکوردهای تکراری
  e2e-*.mjs, test-*.ts     تست‌های سینک/محاسبات/فاکتور/کد جعبه
